## 藏在套餐外的那几张账单

**流量超额**。轻量套餐都给固定月流量，超出后中国内地按 0.8 元/GB 计费。38 元那款只有 300GB 月流量，折算下来每天 10GB，视频、下载、图床类业务很容易打穿。买之前先估一下月流量：日均 IP 乘平均页面大小乘访问页数，出来超过套餐额度就得换档或者准备补钱。

**带宽口径**。市面上三种说法混着用。阿里云轻量的 200M 是峰值带宽，实际持续吞吐受流量包和调度限制，但它标了不限流量；腾讯云锐驰型的 200M 是无限流量峰值带宽；京东云、芯飞云标的 5M、10M 通常是独享带宽。轻量套餐标注的带宽一律是峰值，不等于你随时能跑满。

**代金券不通用**。腾讯云的活动特价机型（38 元、109 元这类）不能叠加代金券，券只能用在常规产品的新购、续费和升级上，个人最高领 1910 元，企业最高 4580 元。想用券就别盯着秒杀款。

**身份决定价格**。腾讯云的低价多限“产品新用户”（该产品下没有历史订单）或个人认证，企业认证和老用户的价格可能上浮 3 到 5 倍，也进不了个人专享秒杀和买赠专区。用公司账号去买个人专享款，价格会当场变脸。

## 什么时候必须多花两三倍的钱买 CVM/ECS

同样配置，常规云服务器（腾讯云 CVM、阿里云 ECS）的价格通常是轻量应用服务器的 2 到 3 倍。这笔钱买的是轻量给不了的东西：VPC 自定义网络、负载均衡、弹性伸缩、多网卡、独立带宽不限流量、更完整的监控和快照体系。

判断标准不复杂。单机跑一个网站、一个接口服务、一个测试环境，轻量够了。出现下面任一情况就该换 CVM/ECS：需要两台以上机器做高可用、需要挂负载均衡、流量波动大要自动扩缩容、需要和数据库或对象存储放在同一 VPC 内网互通。

## 常见疑问

**为什么有的 38 元，有的 780 元？** 38 元是限量秒杀价，780 元是同款套餐的日常价和续费价。秒杀有库存、场次和身份三重限制，日常价才是这台机器长期的真实成本。

**秒杀抢不到怎么办？** 阿里云退到 68 元常规价，腾讯云退到 109 元。别在秒杀上耗时间，差价通常不到一百元，等两场的时间成本比这高。

**峰值带宽和独享带宽差在哪？** 峰值是上限，实际速率由调度和流量策略决定，闲时可能跑满，忙时跑不满；独享是恒定速率，标 5M 就一直是 5M。轻量套餐标注的带宽基本都是峰值。

**流量超了怎么算？** 中国内地 0.8 元/GB，按实际超出量线性计费。阿里云部分轻量套餐标了不限流量，那条限制就不存在，但会受峰值带宽约束。

**企业认证为什么更贵？** 个人专享秒杀、买赠专区、首单折扣这些活动，企业账号进不去。企业能买的是“个企同享”和“企业专区”档位，价格体系不同。

**GPU 服务器一年多少钱？** 另一个量级。阿里云 A10（32 核 188G）3203.99 元/月，T4（4 核 15G）1681 元/月，V100（8 核 32G）3817 元/月，L20（8 核 64G）6929.25 元/月。按月付，年付要乘 12 再看折扣。
